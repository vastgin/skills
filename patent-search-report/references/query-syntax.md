# Google Patents 检索语法与参数（实测口径）

## 1. 两条路：`-q/--query` 还是 `--raw`

- `-q "液冷 充电桩"` —— 只放**检索词/检索式**，过滤条件走各自的参数（推荐，参数会被正确编码）。
- `--raw "q=TI=(充电桩) AND AB=(液冷)"` —— 逃生通道，整串直接拼进 URL query，适合参数没覆盖的写法。
  两者可同时用，`--raw` 在前、`-q` 在后，最终拼成 `q=...&q=...`（Google 会把两个 q 都当检索词）。

## 2. 检索式写法（`-q` 里可用）

| 写法 | 含义 | 实测 |
|---|---|---|
| `充电桩 液冷` | 空格 = 隐式 AND | ✅ |
| `充电桩 AND 液冷` / `OR` / `NOT` | 布尔 | ✅ |
| `"固态电解质"` | 短语精确匹配 | ✅ |
| `TI=(充电桩)` | 限定标题 | ✅ 668 条（配 `AB=(液冷)`） |
| `AB=(液冷)` | 限定摘要 | ✅ |
| `CL=(负极)` | 限定权利要求 | ✅ |
| `CPC=H01M10/0562` | 分类号 | ✅ |
| `(充电桩) AND (液冷)` | 括号分组 | ✅ |

> `NOT` 的两种写法都行：`液冷 NOT 风冷`、`液冷 -风冷`。

## 3. 过滤参数（脚本参数 → URL query）

| 脚本参数 | 取值 | 说明 |
|---|---|---|
| `--country` | `CN` / `CN,US,EP` | 受理局。多个用逗号分隔 |
| `--language` | `CHINESE` / `ENGLISH` | **文献原文语言**，不是界面语言 |
| `--status` | `GRANT` / `APPLICATION` | 已授权 / 申请 |
| `--type` | `PATENT` / `DESIGN` | 类型；外观设计公开号以 `S` 结尾（如 CN308204199S） |
| `--assignee` | 申请人/专利权人 | 中文名可用全称，实测 `腾讯科技（深圳）有限公司`、`宁德时代新能源科技股份有限公司` 均有效 |
| `--inventor` | 发明人 | 同上 |
| `--before` / `--after` | `priority:YYYYMMDD`、`publication:YYYYMMDD`、`filing:YYYYMMDD` | **必须写完整 8 位日期**。写 `priority:2024` 会得到 0 条（实测） |
| `--sort` | `new` / `old` | 按日期倒序 / 正序 |
| `--limit` | 整数，默认 10 | 最多返回多少条；>100 会自动翻页 |
| `--page` | 从 0 起 | 起始页 |

时间窗示例（2023–2024 年优先权）：

```sh
search.py -q "液冷" --country CN --after priority:20230101 --before priority:20241231 --limit 50
```

## 4. 分页与条数上限（实测）

- 单页上限 **100 条**；传 `num<10` 会被服务端按 **10** 处理。脚本已自动把页大小夹在 10–100。
- 翻页**最多到第 100 页**（`total_num_pages` 恒 ≤100），也就是单次检索最多够到约 1 万条。
- 需要更多，就用更细的条件（分类号 / 日期窗 / 申请人）切分，而不是硬翻页。

## 5. ⚠️ `total` 是量级参考，不是精确命中数

`total_num_results` 对宽泛词会**饱和**：实测 `充电桩`、`液冷`、`液冷 NOT 风冷` 三者都报 **124922**，
`桩` 报 125048，`充电` 报 124797 —— 同一量级的不同数字，明显是估值而非计数。

- 报给用户时说「**约 XX 万条量级**」，不要说「命中 124922 条」。
- 要精确计数：先叠加 `--status` / `--type` / 日期窗 / 分类号把集合收窄，再按页取并数实际条数。

## 6. 常见检索场景配方

```sh
# 某公司近年授权专利
search.py --assignee "华为技术有限公司" --country CN --status GRANT \
          --after priority:20220101 --limit 100 --sort new

# 某技术主题的中国发明专利，看最早的都是谁在做
search.py -q "固态电池 界面" --country CN --type PATENT --sort old --limit 30

# 某分类号下某时间窗的全部公开
search.py --raw "q=CPC=H01M10/0562" --country CN \
          --after publication:20240101 --limit 100

# 只想看看某词有多少量级（收窄后）
search.py -q "钠离子电池 正极材料" --country CN --status GRANT --limit 1 --format table
```
