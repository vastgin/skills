# 图表 → 终端文本的降级规则

服务端只回**渲染就绪的数据结构**（`ChartModelDTO`），**不回 ECharts option**（0068 决策 2）。
页面用 ECharts 画，终端没有画布 —— 本文件定义"什么图型降级成什么文本"。

## 总原则

1. **数字不许变**：降级只换呈现形态，不改数值、不改精度、不改顺序。字符条形图是**视觉辅助**，
   必须标注比例尺（`每格 ≈ X`），让读者能反推原值。
2. **不假装画出来**：终端表达不了的图型（热力图矩阵、箱线、K 线、矩形树）
   一律**出数据表 + 一句话说明**，不要用"大概的形状"糊弄。
3. **截断必须标注**：`dataset.truncated=true` 时在标题后加「（结果已截断，非全量）」，
   并明确告知不得据此做合计陈述。
4. **多系列用表格承载**：拆分维度（`colors`）产生的多个系列在终端里就是多列，
   不要试图画并列柱状图。

## 文本形态

### `metric-card`（指标卡 / 单值）

```
**待缴年费笔数** 42
**应缴金额（CNY）** 128,600.00
```

无维度时一张卡 = 一行；有维度时每个维度取值一张卡，前缀维度取值：`2026 · 已缴笔数 128`。

### `table`（明细表）

直接用返回的 `dataset`：

```
| 费款所属年 | 缴纳状态 | 笔数 |
| --- | --- | --- |
| 2025 | 待缴 | 42 |
```

行序就是服务端给的顺序（按维度取值首次出现分层稳定），**不要重排**。

### `bar` / `line` / `pie`（分类图）

两段式：先表格（数字全），再字符条形图（直观）。

```
| 币种 | 待缴笔数 |
| --- | --- |
| CNY | 42 |
| USD | 11 |
| EUR | 5 |

待缴笔数（每格 ≈ 2.10）
CNY  ████████████████████  42
USD  █████                11
EUR  ██                    5
```

- 条形图只画**第一个系列**，条宽固定 20 格，按该系列最大值等比换算。
- 出现负值时**不画条形图**（比例语义会失真），只出表格并说明"含负值，终端不出条形图"。
- 类别名过长（> 12 字符）截断为前 11 字符 + `…`。

### `heatmap`（热力图）

矩阵表：行 = `matrix.yLabels`，列 = `matrix.xLabels`，空单元格为 `0`。

```
| 年 \ 币种 | CNY | USD |
| --- | --- | --- |
| 2025 | 42 | 3 |
| 2026 | 128 | 7 |

（热力图已降级为矩阵表；色泽深浅语义在终端不可用，数值见单元格）
```

### `boxplot` / `candlestick`

出统计量表格，不出图：

```
| 类别 | 最小 | Q1 | 中位 | Q3 | 最大 |
```
```
| 类别 | 开盘 | 收盘 | 最低 | 最高 |
```

### `treemap` / `sunburst`（层级树）

缩进列表，父节点值来自服务端（非叶子为其子节点之和）：

```
- 2026 (135)
  - CNY (128)
  - USD (7)
- 2025 (45)
```

### `gauge` / 单值兜底

`view.singleValue` 非空时按指标卡渲染一行：`**{singleLabel}** {singleValue}`。

## 数字格式

- 整数：千分位（`128,600`）。
- 小数：超过 2 位小数的保留 2 位（`128,600.00` → `128,600`；`1.234` → `1.23`）。
- 比率/分位数（boxData、candleData）：保留 4 位有效小数，去掉尾随零。
- **不做本地币种换算**：币种原样带出（金额指标必须绑定 `currency` 维度，跨币种不可求和）。

## 收尾

渲染完在正文**之外**（stderr 或单独一段）提示调用方：

- 这次用的数据集与口径（供 agent 转述，避免用户以为"算出来了"但不知依据）；
- 是否截断；
- 图型是否发生了降级（降级了就说降成了什么）。
