# 登录引导（Step 2）

CNIPA 案件查询平台登录 = SSO 扫码 + 滑块验证，**无法无人值守自动登录**，必须由用户本人在浏览器里完成。agent 只负责打开页面、给话术、判定结果。

## 开场话术

> 接下来需要您本人登录国家知识产权局账号。我会打开登录页，请您用手机扫码并完成滑块验证。整个过程约 1 分钟，完成后告诉我一声即可。登录凭证只保存在本浏览器会话中，不会上传。

## 操作流程

1. 用 BrowserSkill（`bsk`）打开入口页：`https://cpquery.cponline.cnipa.gov.cn/chinesepatent/index`（可用性检查与安装引导见 `browser-skill-setup.md`）
2. 若出现免责声明/公告弹窗（按钮文案「我知道了」「同意」「关闭」），点掉。
3. 引导用户点击「登录」并完成扫码+滑块。
4. 等待用户确认后判定登录态（见下）。

## 登录成功判定（两条件同时满足）

- **URL 已离开 SSO 登录域**：`tysf.cponline.cnipa.gov.cn` / `sso.cponline.cnipa.gov.cn`
- **页面出现「退出」字样**（有登录态才有退出按钮）

判定失败处理：再等 30s 复查一次；仍未成功则提示用户重试，**禁止尝试自动填写账号密码或自动过滑块**。

## 掉线恢复（采集过程中 URL 回到 SSO 域）

1. **立即停止采集**，当前申请号记 `error`，failReason=`登录态失效`。
2. 告知用户：

> 登录已失效（平台会话超时属正常现象）。请您重新扫码登录，已成功采集的 N 条数据不受影响，剩余 M 条等您登录后继续。

3. 用户重新登录判定成功后，从剩余清单继续（已成功的不重跑）。
4. 同一次会话掉线 ≥3 次：停下来，建议用户检查网络或换时间段再跑，剩余号码记 `error`。
